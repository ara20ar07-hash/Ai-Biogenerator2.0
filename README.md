🤖 AI Social Media Bio Generator
An AI-powered tool that creates personalized, creative, and engaging social media bios based on your personality, style, and goals. Designed to help users quickly build a strong and memorable online presence.

✨ Features
🎯 Generate unique bios in seconds
🧠 AI-powered personalization
🎨 Multiple tones (pro, funny, edgy)
📱 Works for different platforms (Instagram, TikTok, Twitter, etc.)
⚡ Fast and simple to use
🚀 How It Works
Enter a few details about yourself:

A small description of the platform
Personality traits
Desired tone (funny, pro, edgy)
Click Generate

Get multiple bio suggestions instantly

🛠️ Tech Stack
HTML

💡 Example
Input:

Interests: Fitness, studying, self-growth
Tone: Motivational
Output:

"Chasing goals, building discipline, becoming better every day 💪📚"
